# outputs/explanations/layered 目录说明

本目录存放分层解释与证据研判输出。

- confirmed_suspect_explainability_audit.csv：59 个确认嫌疑账户解释审计
- layered_explainability_coverage.json：解释覆盖统计
- risk_review_queue_active_accounts.csv：Top30 主动巡检有边账户
- risk_review_queue_top20_associations.csv：Top20 关联账户
- risk_review_queue_suspicious_paths.csv：多跳可疑路径
- risk_review_queue_fund_flow_structures.csv：资金汇聚、分散、闭环结构
- suspect_link_recovery_queue.csv：56 个缺边账户补数恢复队列
