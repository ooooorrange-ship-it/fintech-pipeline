# docs/images 目录说明

本目录存放《演示文档.md》（位于上一级 docs/ 目录）中需要插入的网页截图和终端截图。


## 二、截图清单

| 文件名 | 演示文档位置 | 打开和操作步骤 | 截图重点 |
|---|---|---|---|
| 01_网页首页总览.png | 第 4 节“网页怎么看” | 直接双击 `outputs/dynamic_graph/index.html`，或用 HTTP 服务打开 | 顶部指标栏 + 动态图谱整体布局 |
| 02_动态图谱操作.png | 第 5.1 节“动态图谱页” | 点击左侧高风险账户，再点击中间的时间窗口按钮 | 滚动子图 + 窗口轨迹 + 右侧研判证据 |
| 03_59账户审计.png | 第 5.2 节“59 账户审计页” | 点击顶部“59账户审计”页签 | 59 条审计记录完整表格 |
| 04_审计筛选与详情.png | 第 5.2 节“59 账户审计页” | 点击“D 缺边审计”筛选按钮，再点击表格任意一行 | 筛选结果 + 下方审计详情 |
| 05_缺边恢复.png | 第 5.3 节“缺边恢复页” | 点击顶部“缺边恢复”页签 | 56 个缺边账户恢复队列 |
| 06_Top30风险巡检.png | 第 5.4 节“Top30 风险巡检页” | 点击顶部“Top30风险巡检”，再点击一个有链路证据的账户 | 巡检表格 + Top20 关联、多跳路径、资金结构 |
| 07_辅助研判报告.png | 第 5.5 节“辅助研判报告页” | 点击顶部“辅助研判报告”页签 | 报告卡片 + 报告原文 |
| 08_终端审计通过截图.png | 第 3.2 节“快速查看已交付结果” | 运行 `python src/14_submission_audit.py` 和 `python src/13_final_project_audit.py` | 两个命令的 `status: pass`、`error_count: 0` 输出 |
