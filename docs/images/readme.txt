# docs/images 目录说明

本目录存放《演示文档.md》（位于上一级 docs/ 目录）中需要插入的网页截图和终端截图。

## 一、命名规则

- 文件名必须与下表完全一致，包括下划线和中文。
- 图片放入本目录后，演示文档中的 `![...](images/xxx.png)` 会自动显示。
- 建议使用 PNG 格式；单张宽度约 1600px，大小不超过 2MB。
- 不要上传与演示无关的截图，避免压缩或拉伸变形。

## 三、截图方法

Chrome 整页截图：

1. 用 HTTP 服务打开页面（推荐）：
   ```bash
   cd outputs/dynamic_graph
   python -m http.server 8080
   ```
   浏览器访问 `http://localhost:8080/`。
2. 按 F12 打开开发者工具。
3. 按 Ctrl+Shift+P，输入 `Capture full size screenshot` 回车，保存整页截图。

Chrome 窗口截图：

1. 把窗口调整到需要的宽度（建议 1440px）。
2. 按 Cmd+Shift+4，拖选要截取的区域。

macOS 窗口截图：

1. 按 Cmd+Shift+4。
2. 再按空格，点击目标窗口。

终端截图：

1. 打开终端进入项目根目录。
2. 依次运行两个审计命令。
3. 截图时确保能看到 `status: pass` 和 `error_count: 0`。

## 四、插入后检查

- 文件名是否与表格完全一致。
- 在 Typora、VSCode 或 GitHub 的 Markdown 预览中能否正常显示。
- 图片内容与所在章节是否对应，例如“01 首页”不能放成审计页。
- 演示前打开一次 `docs/演示文档.md`，确认 8 张图片全部显示且没有破图。
