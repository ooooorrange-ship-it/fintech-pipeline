# 双层研判架构技术说明

## 1. 为什么要设计双层研判架构

本赛题要求围绕动态交易关系完成三件事：

1. 涉诈账户识别。
2. 可疑关联账户和资金链路解释。
3. 辅助研判报告生成。

但当前脱敏数据存在一个客观限制：测试集 59 个确认嫌疑账户中，只有 3 个账户在交易边表中存在可追溯历史交易边，其余 56 个账户没有任何入边或出边。

因此，不能把 59 个账户都硬生成资金链路。这样会产生无依据解释，反而不符合赛题对“证据可信可用”的要求。

原始数据核验已固化为可复现审计：交易边表去重端点账户为 7795/11087，时间覆盖 2025-07 至 2025-12；59 个确认嫌疑账户中只有 3 个（1740、4379、7265）是端点，其余 56 个不是任何一条交易边的付款方或收款方。该缺边与清洗规则、ID 类型或时间窗口过滤无关。详见 `docs/data_edge_coverage_audit.md`。

本项目采用双层研判架构解决这个问题：

```text
第一层：动态资金图谱识别层
输入：账户节点 + 转账边 + 时间分桶 + 金额分箱 + 风险标签
输出：全量账户风险分数、TopK 高风险账户、动态特征证据

第二层：分层证据研判层
输入：模型分数 + 历史交易边覆盖状态 + 关联账户 + 可疑路径 + 资金结构
输出：有边账户的真实链路解释；无边账户的缺边审计和补数恢复队列
```

这个架构的核心原则是：

> 有真实交易边的账户，给出可核验资金链路；没有真实交易边的账户，不伪造路径，而是给出模型依据、节点画像、缺边原因和补数查询。

## 2. 第一层：动态资金图谱识别层

第一层解决“谁最可疑”的问题。

项目按账户构建节点，按转账构建有向边，并按 train、valid、test 的时间 cutoff 构建 120 天滚动历史资金图。模型只使用截至当前 split end 的历史交易，不使用未来交易。

当前最终主模型为：

```text
model11_validation_selected_best_strategy_A
```

模型由验证集自动选择权重：

```text
0.75 * Model8 当前最佳模型
+ 0.20 * CatBoost 动态特征模型
+ 0.05 * 轻量 TGN 时间事件流模型
```

CatBoost 和 TGN 都是新增对照分支。当前正样本只有 59 个，TGN 的验证效果弱于树模型，因此只保留 0.05 权重；GraphSAGE 仍作为独立消融，不为了技术名称牺牲效果。

第一层使用的主要特征包括：

| 特征组 | 作用 |
|---|---|
| 交易统计特征 | 描述账户入账、出账、金额、频次、活跃度 |
| 时间分桶特征 | 描述周、日、小时、夜间交易分布 |
| 金额分箱特征 | 用 train 分位数生成金额箱，避免 valid/test 泄露 |
| 动态图快照特征 | 描述滚动窗口内入度、出度、活跃周数、度数波动 |
| 时序资金流模体 | 捕捉快进快出、多入一出、一入多出、闭环回流 |
| 节点记忆特征 | 用时间衰减刻画近期交易状态 |
| 图结构特征 | 描述二跳邻居、PageRank、互惠关系、连通分量等 |

正式测试结果：

| 指标 | 结果 |
|---|---:|
| AUC | 0.9858 |
| PR-AUC | 0.8049 |
| Top1% 命中 | 51/59 |
| Top5% 命中 | 56/59 |
| Top5% 确认风险覆盖率 | 94.92% |

第一层结论：

> 模型可以在全量账户中给出稳定的高风险排序。若只复核风险最高的前 5% 账户，可以覆盖 59 个确认嫌疑人中的 56 个。

## 3. 第二层：分层证据研判层

第二层解决“为什么可疑、证据在哪里”的问题。

由于交易边覆盖不完整，项目不采用单一解释口径，而是将账户分成四类：

| 等级 | 名称 | 说明 | 输出方式 |
|---|---|---|---|
| A | 链路证据型 | 有多跳路径、闭环、汇聚或分散结构 | 输出可疑路径、关键交易边、资金结构 |
| B | 直接关联型 | 有直接交易对手，但缺少复杂多跳结构 | 输出 Top20 关联账户和直接边证据 |
| C | 动态特征型 | 有交易统计或动态图异常，但链路结构弱 | 输出模型分、动态特征和账户画像 |
| D | 数据缺边型 | 当前交易边表没有覆盖该账户 | 输出缺边审计和补数恢复队列 |

当前测试集确认嫌疑账户覆盖情况：

| 类型 | 数量 |
|---|---:|
| A 链路证据型 | 1 |
| B 直接关联型 | 2 |
| D 数据缺边型 | 56 |
| 账户审计覆盖 | 59/59 |
| 真实链路覆盖 | 3/59 |

第二层结论：

> 真实资金链路只能覆盖有交易边的账户；但账户级审计可以覆盖全部 59 个确认嫌疑账户。对缺边账户，系统不会生成虚假链路，而是形成可执行的补数恢复队列。

## 4. 有交易链路的账户如何研判

对 A/B 类账户，系统输出真实交易证据。

已发现的典型案例：

| 账户 | 等级 | 研判类型 | 说明 |
|---|---|---|---|
| 4379 | A | 强时序闭环 | 存在可追溯资金链路和近似回流结构 |
| 1740 | B | 稳定星状网络 | 与少量固定对手重复交易 |
| 7265 | B | 边缘微小试探 | 交易规模小、连接弱，疑似试探或养号 |

这类账户的报告可以引用：

1. 模型风险分数。
2. 账户交易统计特征。
3. Top20 关联账户。
4. 多跳可疑路径。
5. 闭环回流、汇聚、分散等资金结构。

对应产物：

| 文件 | 作用 |
|---|---|
| `outputs/deliverables/task3_top20_associations.csv` | Top20 关联账户 |
| `outputs/deliverables/task3_suspicious_paths.csv` | 多跳可疑路径 |
| `outputs/deliverables/task3_fund_flow_structures.csv` | 资金结构 |
| `docs/task3_typical_cases.md` | 典型案例 |
| `docs/task3_link_visualization_samples.md` | 链路可视化样例 |

## 5. 没有交易链路的账户如何研判

需要明确：56 个缺边账户在 Model11 测试集平均风险分为 0.9847，但交易统计、图结构、动态资金图谱特征均为 0，其高分主要来自账户画像与图基座特征，属于画像层研判，不是资金行为链路证据；账户级五折留出验证 Top5% 召回约 44%，应作为补数复核线索，而不是已证实资金链路。

对 D 类账户，系统不生成资金路径，而是输出缺边审计。

原因是：如果账户在当前交易边表中没有任何入边或出边，那么算法无法凭空恢复真实交易链路。此时“没有链路解释”不是模型失败，而是数据边界限制。

D 类账户的研判方式是：

```text
模型风险分数
  + 账户节点画像
  + 动态/统计风险特征
  + 缺边状态
  + 补数查询字段
  = 可复核的缺边审计报告
```

这类账户的业务含义可能包括：

1. 标签来自行方处置记录、案件名单或外部风险来源，而当前抽样交易边没有覆盖其真实交易。
2. 账户属于风险账户邻域抽样中的节点，但核心交易发生在抽样窗口之外。
3. 账户被风险标签表确认，但交易流水在脱敏、抽样、字段精简过程中缺失。

对应产物：

| 文件 | 作用 |
|---|---|
| `outputs/explanations/layered/confirmed_suspect_explainability_audit.csv` | 59 个确认嫌疑账户解释覆盖审计 |
| `outputs/explanations/layered/suspect_link_recovery_queue.csv` | 56 个缺边账户补数恢复队列 |
| `docs/confirmed_suspect_explainability_audit.md` | 59 个账户审计说明 |

## 6. 面向答辩的推荐表述

推荐这样讲：

> 我们专门研发了双层研判架构。第一层是动态资金图谱识别层，负责在全量账户中识别高风险涉诈账户；第二层是分层证据研判层，负责根据交易边覆盖情况生成不同级别的解释。对有真实交易边的账户，系统输出 Top20 关联账户、多跳可疑路径和资金结构；对没有交易边的账户，系统不伪造链路，而是输出模型分数、账户画像、缺边审计和补数恢复队列。因此，模型识别可以覆盖全量账户，证据研判也能覆盖 59 个确认嫌疑账户，只是解释证据分为链路证据和缺边审计两种形态。

不要这样讲：

```text
我们解释了全部 59 个嫌疑人的资金链路。
```

因为事实是：

```text
真实资金链路覆盖 3/59；
账户审计覆盖 59/59。
```

更严谨的表述是：

```text
我们实现了 59/59 的账户级审计覆盖，其中 3 个账户具有真实资金链路证据，56 个账户进入缺边恢复队列。
```

## 8. 一句话总结

本项目不是把所有账户强行解释成资金链路，而是把解释拆成“真实链路证据”和“缺边审计证据”。这更符合脱敏金融数据的真实边界，也更符合赛题对可追溯、可信、可复核研判证据的要求。
