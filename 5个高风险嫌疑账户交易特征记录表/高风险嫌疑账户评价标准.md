# 高风险嫌疑账户评价标准

## 概述

本评价标准基于赛题"基于资金图谱的涉诈账户发现与可疑链路解释"的业务场景，围绕黑产资金6类典型流转模式（分散入账、多层跳转、快进快出、金字塔归集、环形转账、跑分账户集群），设计**三维度加权风险评分体系**，对59个嫌疑人账户进行定量风险评估。

---

## 一、评分体系总览

```
综合风险评分 = 直接交易风险评分 + 关联网络风险评分 + 账户特征风险评分
```

| 维度 | 满分 | 权重定位 | 数据来源 |
|------|------|----------|----------|
| 直接交易风险 | ~54分 | **核心维度**，反映账户自身交易行为画像 | 交易边表 |
| 关联网络风险 | ~46分 | **增强维度**，反映资金图谱中的拓扑风险传导 | 交易边表 + 风险标签表 |
| 账户特征风险 | ~8分  | **辅助维度**，反映账户静态属性风险 | 账户表 |

---

## 二、直接交易风险评分（满分 ~54分）

> 数据来源：交易边表中涉及该嫌疑人的所有直接交易记录（作为付款方或收款方）。

### 2.1 快进快出（满分 +8分）

**业务背景**：涉诈账户典型特征——当日入账、当日全额转出，无资金沉淀。

| 条件 | 加分 | 判定逻辑 |
|------|------|----------|
| 有入有出，且\|总入-总出\| / max(总入,总出) < 10% | **+8** | 资金进出高度平衡，典型洗钱过账 |
| 有入有出，且差额比 < 30% | **+4** | 资金部分留存，可能分散转出 |
| 仅有单向交易（纯入或纯出） | 0 | 不触发快进快出 |

### 2.2 资金流量规模（满分 +10分）

**业务背景**：涉诈资金往往通过多笔累积成大额流转。

| 条件 | 加分 |
|------|------|
| 总资金流量（入+出）> 10,000,000 | **+10** |
| 总资金流量 > 1,000,000 | **+5** |
| 总资金流量 > 100,000 | **+3** |
| 总资金流量 > 0 | **+1** |

### 2.3 交易频次（满分 +10分）

**业务背景**：跑分账户集群特征——短时间内大量交易。

| 条件 | 加分 |
|------|------|
| 交易笔数 > 100 | **+10** |
| 交易笔数 > 50 | **+7** |
| 交易笔数 > 20 | **+5** |
| 交易笔数 > 5 | **+3** |
| 交易笔数 > 0 | **+1** |

### 2.4 夜间交易占比（满分 +8分）

**业务背景**：22:00-次日06:00集中转账，脱离居民正常作息，为涉案账户标准特征。

| 条件 | 加分 |
|------|------|
| 夜间交易占比 > 50% | **+8** |
| 夜间交易占比 > 30% | **+5** |
| 夜间交易占比 > 10% | **+2** |

> 夜间定义：`hour >= 22 or hour < 6`（基于交易时间字段解析）

### 2.5 交易对手分散度（满分 +10分）

**业务背景**：短期频繁切换陌生交易对手，无长期固定往来账户。

| 条件 | 加分 |
|------|------|
| 对手账户数 > 50 | **+10** |
| 对手账户数 > 30 | **+7** |
| 对手账户数 > 15 | **+4** |
| 对手账户数 > 5 | **+2** |
| 对手账户数 > 0 | **+1** |

### 2.6 平均交易金额（满分 +5分）

**业务背景**：大额平均交易金额可能反映集中归集/拆分行为。

| 条件 | 加分 |
|------|------|
| 平均交易金额 > 100,000 | **+5** |
| 平均交易金额 > 50,000 | **+3** |
| 平均交易金额 > 10,000 | **+1** |

### 2.7 交易密度（满分 +5分）

**业务背景**：短时间内高频交易，反映异常活跃度。

| 条件 | 加分 |
|------|------|
| 交易时间跨度>0 且 笔数/跨度(天) > 20 | **+5** |

## 三、关联网络风险评分（满分 ~46分）

> 数据来源：基于全部904,395条交易边构建的资金图谱，计算1跳（直接邻居）和2跳（邻居的邻居）关联关系。

### 3.1 1跳关联账户规模（满分 +10分）

**业务背景**：直接交易对手越多，资金分散/汇聚特征越明显。

| 条件 | 加分 |
|------|------|
| 1跳关联账户数 > 100 | **+10** |
| 1跳关联账户数 > 50 | **+7** |
| 1跳关联账户数 > 20 | **+4** |
| 1跳关联账户数 > 0 | **+1** |

### 3.2 1跳关联受害者（满分 +10分）

**业务背景**：直接与受害人发生交易，是涉诈账户最核心的风险信号。

| 条件 | 加分 |
|------|------|
| 1跳受害者数 > 10 | **+10** |
| 1跳受害者数 > 5 | **+7** |
| 1跳受害者数 > 0 | **+3** |

### 3.3 2跳关联受害者（满分 +8分）

**业务背景**：通过1层中介间接关联受害人，反映团伙化、多层跳转特征。

| 条件 | 加分 |
|------|------|
| 2跳受害者数 > 20 | **+8** |
| 2跳受害者数 > 10 | **+5** |
| 2跳受害者数 > 0 | **+2** |

### 3.4 1跳关联嫌疑人（满分 +8分）

**业务背景**：嫌疑人之间直接交易，强烈暗示团伙协同作案。

| 条件 | 加分 |
|------|------|
| 1跳嫌疑人关联数 > 5 | **+8** |
| 1跳嫌疑人关联数 > 0 | **+3** |

### 3.5 2跳关联嫌疑人（满分 +5分）

**业务背景**：通过中介连接其他嫌疑人，反映更大范围团伙网络。

| 条件 | 加分 |
|------|------|
| 2跳嫌疑人关联数 > 10 | **+5** |
| 2跳嫌疑人关联数 > 0 | **+2** |

### 3.6 2跳网络覆盖规模（满分 +5分）

**业务背景**：2跳可达账户数越大，该嫌疑人在资金网络中的影响力/辐射范围越广。

| 条件 | 加分 |
|------|------|
| 2跳可达账户数 > 200 | **+5** |
| 2跳可达账户数 > 100 | **+3** |

## 四、账户特征风险评分（满分 ~8分）

> 数据来源：账户表中的静态属性（开户时长、客户类型、地区编码）。

### 4.1 开户时长（满分 +8分）

**业务背景**：涉诈账户多为短期开设、快用快弃，开户时长越短风险越高。

| 条件 | 加分 | 风险等级 |
|------|------|----------|
| 开户时长 < 3个月 | **+8** | 🔴 高危 |
| 开户时长 < 6个月 | **+5** | 🟠 中危 |
| 开户时长 < 12个月 | **+3** | 🟡 关注 |
| 开户时长 >= 12个月 | 0 | 正常 |

---

## 五、风险等级划分

| 综合评分 | 风险等级 | 含义 |
|----------|----------|------|
| ≥ 25 | 🔴 **极高风险** | 多项交易+网络+账户特征同时触发 |
| 15-24 | 🔴 **高风险** | 交易行为或网络关联存在显著异常 |
| 8-14 | 🟠 **中风险** | 个别维度存在风险信号 |
| 3-7 | 🟡 **低风险** | 仅账户特征或弱信号触发 |
| 0-2 | ⚪ **待观察** | 当前数据中无明显风险信号 |

## 六、评分权重设计依据

| 黑产资金流转模式 | 对应评分项 | 总分值 |
|------------------|-----------|--------|
| **快进快出** | 2.1 快进快出(+8) + 2.7 交易密度(+5) | 13分 |
| **分散入账** | 2.3 交易频次(+10) + 2.5 对手分散度(+10) + 3.1 1跳规模(+10) | 30分 |
| **多层跳转** | 3.2 1跳受害者(+10) + 3.3 2跳受害者(+8) + 3.6 2跳规模(+5) | 23分 |
| **金字塔归集** | 2.2 资金规模(+10) + 2.6 平均金额(+5) | 15分 |
| **环形转账** | 2.1 快进快出(+8) + 3.4 嫌疑人互联(+8) | 16分 |
| **跑分集群** | 2.3 交易频次(+10) + 2.4 夜间交易(+8) + 3.4/3.5 嫌疑人关联(+13) | 31分 |

## 七、当前局限性与改进方向

### 7.1 数据层面

| 局限 | 影响 | 改进方向 |
|------|------|----------|
| 子图抽样（仅3/59人有直接交易） | 56人直接交易评分为0，依赖网络和账户维度 | 扩大抽样跳数/全量数据 |
| 缺少交易渠道、交易类型字段 | 无法区分网银/柜面、转账/消费 | 引入更多边特征 |
| 缺少借贷方向字段 | 无法区分借方/贷方交易 | 补充交易标志 |
| 时间仅到秒级分桶 | 无法精确计算交易间隔 | 使用毫秒级时间戳 |

### 7.2 方法层面

| 局限 | 改进方向 |
|------|----------|
| 权重为启发式设定，未经调优 | 使用网格搜索/贝叶斯优化调参 |
| 各维度独立评分，未建模交互 | 引入XGBoost/LightGBM自动学习特征交互 |
| 图网络评分仅到2跳 | 使用GNN(GAT/GCN)学习多跳节点嵌入 |
| 阈值基于经验设定 | 基于标签分布使用百分位数动态阈值 |
| 未考虑时间演化 | 引入时序图神经网络(TGN)建模动态网络 |

### 7.3 业务层面

| 局限 | 改进方向 |
|------|----------|
| 未区分标签置信度（标签有滞后/漏标/噪声） | 引入半监督学习/PU Learning |
| 未生成结构化研判证据链 | 结合研判模板生成辅助研判报告（赛题任务4） |
| 受害人标签未充分用于网络评分 | 使用Label Propagation传播风险 |
